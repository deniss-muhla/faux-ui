# Changelog

## 0.1.0 — Unreleased

### Added

- Standalone `@faux-ui/grid` package built only on public `@faux-ui/ui` entrypoints.
- CSS-grid-like fixed/auto/fraction tracks and `repeat()` helper.
- Sparse row-major automatic placement with implicit `auto` tracks.
- One-based explicit placement, two-axis spans, and deterministic overlap.
- Independent x/y gaps plus ordinary `Box` appearance, focus, and event props.
- Composition with public `Text` and `ScrollView` instead of Grid-specific text or scrolling shortcuts.
- One portable Agent Skill plus Pi, Codex/ChatGPT, and Claude Code package/plugin discovery metadata.
- Unit, negative type, packed consumer, browser-bundle, TUI, and package-content gates.
